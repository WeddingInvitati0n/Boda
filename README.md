# 💍 Proyecto: Nuestra Boda Digital 

¡Bienvenidos al repositorio oficial de una boda! Este espacio fue creado para diseñar, desarrollar y organizar la invitación digital y el itinerario de uno de los días más importante de la vida de nuestros clientes.

## 🛠️ Stack Tecnológico (Invitación Digital)

Si estás curioseando el código de la invitación, esto es lo que se utilizó para construirla:

* **HTML5 & CSS3:** Estructura limpia y diseño responsivo (*mobile-first*), porque el 95% de los invitados abrirá la invitación desde su teléfono.
* **CSS Flexbox/Grid:** Para que el itinerario en formato de tarjetas o pestañas se alinee perfectamente.
* **Google Fonts:** Fuentes elegantes tipo *Serif* (`Cinzel` / `Lora`) para mantener el tono romántico y formal.
* **FontAwesome:** Para los íconos sutiles del itinerario (copas, anillos, comida).

## 📌 Características Clave del Repositorio

1. **Diseño Compacto:** Optimización de espacio para que los invitados vean toda la información importante sin hacer *scroll* infinito.
